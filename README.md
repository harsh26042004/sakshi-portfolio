# Sakshi Sah - Portfolio

Static portfolio site (HTML + CSS only, no build step).

## Deploy with GitHub Pages
1. Create a new repository and upload `index.html`, `photo.jpg` and `README.md`.
2. Go to Settings > Pages.
3. Under Source choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/` in a minute or two.
